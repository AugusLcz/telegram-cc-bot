# Contributing

Everything you need is in [AGENTS.md](AGENTS.md): commands, repository map, the rules that must hold,
recipes, the definition of done and the release steps. It is written for coding agents and humans alike.

In short: run `npm run check` before every commit, add tests for new behaviour, and update the docs that
the change touches (both READMEs, `docs/ARCHITECTURE.md`, a record in `docs/decisions/` for a design
decision, `CHANGELOG.md` under `Unreleased`).
